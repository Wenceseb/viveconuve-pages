# ViveConUve: edición y publicación

La fuente activa está en este repositorio; `dist/` se genera. Consultar `docs/mantenimiento-editorial.md` antes de editar contenido. Buscar duplicados, borradores y el estado del evento antes de crear páginas.

Desde el 24/11/2026, las nuevas piezas y tandas editoriales se preparan y comprueban en local. Mostrar a Uve el texto final, los cambios, una vista previa móvil/escritorio y los límites antes de publicar. Pedir aprobación del resultado concreto si no ha autorizado expresamente su publicación. No enviar cambios editoriales a `main` ni activar GitHub Pages antes de esa aprobación: el push despliega automáticamente. Las pruebas correctas no equivalen a revisión editorial aprobada.

Respetar la voz en primera persona y el diseño existente. No inventar experiencias, registros, imágenes ni resultados. No alterar relatos históricos para hacerlos parecer posteriores; actualizar las secciones que describen el estado actual. Usar fechas reales y distinguir evento, publicación y modificación.

La crónica de Fuengirola existe en `/athlonx-fuengirola-2026-cronica.html`. No crear otra URL. Mantener el resultado `1.º Open GGEE +55 masculino` y la exclusión de tiempos y participantes de su grupo. Málaga: 17/04/2027. Las plantillas antiguas no prevalecen sobre estos hechos ni sobre instrucciones posteriores de Uve.

Para cambios de contenido o presentación, ejecutar `npm run check`, `npm run format:check` y las pruebas de navegador pertinentes. Enviar formularios únicamente con un destinatario y correo de prueba autorizados; las pruebas locales interceptan los envíos y no crean suscripciones.
